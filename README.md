
医疗大语言模型参数高效微调与偏好对齐优化
2025年11月 – 2025年12月
个人独立实验
项目背景：基于 Qwen2.5-3B 基座模型，通过 SFT（监督微调）与 DPO（直接偏好优化）两个阶段，构建具备专业医疗诊断推演与逻辑对齐能力的垂直领域大模型。

SFT： 1）针对在15k医疗数据集上微调模型后出现基本语义判断力受损（灾难性遗忘）的问题，通过“医疗召回数据 (15k) + 通用对话数据 (2k)”的混合策略，利用通用能力作为“锚点”固化语义逻辑，并通过BGE-small-zh将ceval验证集向量化，在原数据集进行向量召回取前15k医疗数据提升数据质量。采用LoRA来优化显存占用
2）改进后的sft模型在ceval基础医学测试集上准确率从 78.8% 提升至 82.3%，困惑度由9.89降低至8.56

DPO： 1）SFT 模型虽掌握知识但在诊断建议时易产生“幻觉”，且回复倾向于短句堆砌，缺乏深度临床推演。

2）采用QLoRA(4-bit) 方案进行偏好学习。构建2.5k Chosen/Rejected对比对，将“病理推导->诊断分析”医生回复设为正样本，同时混合0.5k ShareGPT通用偏好数据对，通过 DPO 算法直接压低模糊回答的对数概率空间。
3）验证集奖励准确率达到94.5%，最终 DPO 模型在 C-Eval 基础医学评测中达到84% 的准确率。解决了模型在医疗场景下的“回复简短”和“逻辑断层”问题，使回复风格从“关键词堆砌”演变为“具备临床逻辑的专家化表达”。
